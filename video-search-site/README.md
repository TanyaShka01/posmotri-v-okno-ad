# Видеопоиск — Проект с видеокарточками

Этот проект демонстрирует современный интерфейс поиска и просмотра видео с использованием HTML, CSS и JavaScript.

## Структура проекта

```
video-search-site/
├── index.html              # Основная HTML разметка
├── styles/
│   └── style.css          # Основные стили
├── scripts/
│   └── script.js          # Логика приложения
├── fonts/
│   ├── inter.woff2        # Шрифт Inter (современный формат)
│   ├── inter.woff         # Шрифт Inter (альтернативный формат)
│   └── README.md          # Инструкции по установке шрифтов
└── README.md              # Этот файл
```

## Функциональность

### При загрузке страницы
- Загружаются первые 5 видеокарточек
- В основной блок подставляется первое видео
- Отображается кнопка "Показать ещё"

### Интерактивные элементы
- **Клик по карточке** — переключение основного видео
- **Кнопка "Показать ещё"** — загрузка дополнительных карточек (по 5 за раз)
- **Форма поиска** — поиск по названию и описанию видео
- **Чекбоксы** — фильтрация (функции настраиваются)

### Визуальные эффекты
- **Прелоадеры** — показываются во время загрузки данных
- **Текущая карточка** — выделяется жёлтым фоном
- **Состояния интерактивных элементов** — :hover, :active, :focus-visible
- **Скроллбар** — стилизованный скролл в контейнере карточек

### Обработка ошибок
- При ошибке загрузки показывается красное сообщение об ошибке
- При отсутствии результатов поиска выводится соответствующее сообщение

## Технические детали

### HTML структура
- Использованы семантические теги (`<form>`, `<fieldset>`, `<legend>`)
- Шаблоны (`<template>`) для динамической генерации элементов
- Скрытые элементы через класс `.visually-hidden` для доступности

### CSS подход
- **Flexbox** для компоновки основных секций
- **CSS Grid** не требуется, т.к. макет линейный
- **Переменные и медиазапросы** могут быть добавлены при необходимости
- **Объект-fit** для масштабирования видео и изображений

### JavaScript архитектура
- Модульная структура с отдельными функциями
- Mock API для демонстрации (легко заменяется на реальный API)
- Обработка состояний загрузки (preloader, error)
- Динамическое создание элементов из шаблонов

## Размеры и единицы

Страница использует **фиксированные размеры**:
- Ширина: 1280px
- Высота: 720px
- Все отступы и размеры в абсолютных единицах (px)

Это упрощает вёрстку и позволяет достичь точного соответствия макету.

## Шрифты

Проект использует шрифт **Inter** с весами:
- 400 — обычный текст
- 500 — подзаголовки
- 700 — заголовок

Подключение через @font-face в `style.css`.

## Расширение функционала

### Подключение реального API
Замените mock данные в `script.js` на реальные запросы:

```javascript
async function loadVideos() {
  try {
    const response = await fetch(`${API_BASE_URL}?page=${currentPage}`);
    const data = await response.json();
    videos = data.videos;
    renderVideoCards();
  } catch (error) {
    showError(contentList, 'Ошибка загрузки видео');
  }
}
```

### Добавление фильтров
В формеуже добавлены чекбоксы для фильтров. Расширьте функцию `performSearch()` для их использования.

### Локальное хранилище
Добавьте сохранение поисковых истории:

```javascript
function saveSearchHistory(query) {
  let history = JSON.parse(localStorage.getItem('searchHistory')) || [];
  history.unshift(query);
  localStorage.setItem('searchHistory', history.slice(0, 10));
}
```
